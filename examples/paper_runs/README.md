# Paper Runs

This directory contains paper-oriented workflows for the decoder-comparison manuscript:

**Decoder Performance in Hybrid CV-Discrete Surface-Code Threshold Estimation Using LiDMaS+**

This directory now contains the following paper bundles:

- `paper_01/` (frozen scripts and results for reviewers)
- `paper_02/` (current working paper, scripts can diverge)
- `paper_03/` (xanadu hardware-to-decoder replay and integration analyses)
- `paper_04/` (PennyLane-vs-LiDMaS+ decoder interface comparison)

Each bundle is self-contained and includes its own scripts, results directory, and helper tools.

See each bundle’s `README.md` for the workflow map and run commands.
