# Steane [[7,1,3]] CSS Code (Example)

Files in this folder:

- `hx.txt` and `hz.txt`: parity-check matrices (dense 0/1 format)
- `lx.txt` and `lz.txt`: logical operator supports (one or more rows)
- `spec.yaml`: YAML spec referencing the files (recommended)
- `spec.json`: JSON spec referencing the files

Format rules:

- Use only 0/1 entries
- Separate entries with spaces or commas
- One row per line
- Lines starting with `#` or `//` are ignored
